# Upgrade signature juice

## Scope

A cosmetic continuation on the active branch: all **7 catalogue slash styles, 8 dash choices, 7 cores and 10 bodies**, plus the default cloth band. Existing head/eye/tail ability hardware and truthful state readouts are preserved. This is not a claim to have redesigned every sensor, world or wave upgrade in this pass.

No damage, hitbox, attack-source ownership, collisions, target acquisition, charge, cooldown, price, unlock, save or preset changes. **C64 Tide's mechanical bank/pressure migration remains pending.**

## Bodies and cloth

Ten existing physical silhouettes remain. Added restrained edge-owned material work: paper wear/fold, obsidian facets, a projection scan, prism facets, iron panel wear and vents, warm lava seams, burnished gold glint, chamfered metal plates, notched vent etching and segmented spring seams. The face stays open and the shell stays axis-aligned; the previous stacked generic eye/chassis cages are not restored.

The default cloth band has a pinned knot, travelling low-amplitude wind, delayed middle/tip response and damped launch-release recoil. This is a **seekable analytical cloth response**, not a persistent spring/body simulation. It cannot accumulate drift, depend on render frequency or rotate the cube. Existing falling-velocity bend and attack follow-through still contribute. Reduced motion returns exact zero flutter/recoil.

## Review and reproduction

Open `docs/upgrade-juice/index.html` through the running Vite preview; it imports the production module, not duplicated art. `signature-motion.webm` plays without the module. Local browser checks use `/tmp/chromium`, with `LD_LIBRARY_PATH=/tmp/al2023/lib` in this sandbox.

- `node --test test/upgrade-juice.test.js test/action-harmony-fx.test.js test/airy-art.test.js test/core-mechanism.test.js test/head-hardware.test.js`
- `LD_LIBRARY_PATH=/tmp/al2023/lib node scripts/upgrade-juice-browser-qa.mjs`
- `LD_LIBRARY_PATH=/tmp/al2023/lib node scripts/upgrade-juice-motion-qa.mjs`
- `npm test`; `npm run build`; `git diff --check`

Native scripts accept `PREVIEW_URL`, defaulting to port 5192. Full shop and controlled live checks reused the existing exhibit/airy runners with only output paths changed. These are scripted browser/art checks, not recruited-player recognition testing, physical-device FPS claims or Poki certification.
